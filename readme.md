# ViralDownloader 🚀

> ⚠️ **Educational Project Only**

ViralDownloader is a **learning-focused project** built to understand how modern web applications handle:
- frontend ↔ backend communication
- API design with FastAPI
- media streaming concepts
- Docker-based deployments
- CI/CD workflows using GitHub

## 🎯 Purpose of This Project

This repository exists to help developers learn:

- How FastAPI works in real-world scenarios
- How to design token-based APIs
- How streaming responses work in HTTP
- How frontend and backend integrate
- How Docker simplifies deployments
- How CI/CD pipelines work with GitHub

It is meant to be used as:
- a **reference**
- a **learning resource**
- a **personal experiment**

---

## 🛠 Tech Stack

- **Backend:** FastAPI, yt-dlp
- **Frontend:** HTML, Tailwind CSS
- **Deployment:** Docker, VPS
- **CI/CD:** GitHub Actions
